🕊️👨‍💻 Learn Lingo Backend
This is the backend for the Learn Lingo web application, providing REST API endpoints for user authentication, nanny data, and session management.

The backend includes:

- User registration, login, logout, and session handling  
- Nannys collection with details: name, avatar_url, birthday, experience, reviews, education, kids_age, price_per_hour, location, about, characters, rating  
- Favorites handling per user (add/remove nannys)  
- Secure password hashing and token-based sessions  
- Error handling and input validation  

🧰 Tech Stack
Node.js | Express | TypeScript | MongoDB | Mongoose | Axios | bcrypt | http-errors | REST API

💻 Features / My Contribution
- Fully implemented backend with Node.js, Express, and MongoDB  
- Connected frontend (Next.js/TypeScript) to backend API  
- Implemented authentication, session management, and nanny CRUD
